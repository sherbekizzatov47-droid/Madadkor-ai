# Madadkor AI — yangilangan versiya

Ushbu versiyada saytning bosh sahifasi va CASE kabineti yangilandi.

## Qilinganlar
- Hero matni: "Muammoingizni ayting. Madadkor yo‘lini ko‘rsatadi."
- "3 til" va "100% bepul" statistikalari olib tashlanib, mahsulotning real funksiyalariga mos ko‘rsatkichlar qo‘yildi.
- "AI yurist" o‘rniga "Madadkor AI" / "jonli ovozli suhbat" ishlatiladi.
- Call-centerda haqiqiy raqam bo‘lmasa `+998 XX XXX XX XX` o‘rniga "Telefon raqami tez orada ulanadi" ko‘rsatiladi.
- CASE kabineti professionalroq ko‘rinishga o‘tkazildi.
- Har bir CASE uchun "CASEni ochish" oynasi qo‘shildi.
- CASE ichida kategoriya, holat, muhimlik, suhbat xabarlari va AI xulosasi ko‘rinadi.
- CASE ichidan ariza tayyorlashga o‘tish saqlanadi.
- Shu qurilmadagi barcha CASElarni tozalash tugmasi qo‘shildi.
- Ariza va yuborish funksiyalari saqlanib qolgan.

## Ishga tushirish
```bash
npm install
npm run dev
```

## Vapi
`.env` faylida mavjud Vapi Public Key va Assistant ID'laringizni saqlang.
